## 文件说明

| 文件 | 说明 |
| --- | --- |
| `IO1.1_3395_Pro.zip` | 加密压缩包，内含安装程序与本文 README |
| `IO1.1 3395 Pro.exe` | 安装程序源文件（未压缩，可直接运行） |

## 解压密码

```
3395pro
```

## 使用方法

1. 下载 `IO1.1_3395_Pro.zip`。
2. 使用 7-Zip、WinRAR 或 Bandizip 打开，输入密码 `3395pro` 解压。
3. 解压后双击运行 `IO1.1 3395 Pro.exe`，按安装向导提示完成安装。
4. 安装完成后按需打开对应软件进行设备设置。

> 注意：Windows 自带的“解压缩文件夹”不支持密码解压，请使用上述第三方工具。
> 安装程序未做数字签名，若出现 SmartScreen 提示，请核对文件来源后再选择“仍要运行”。
